# CCT360 Lab 4

This project is a simple landing page for a creative media workshop hub. It includes a branded header, hero section, workshop cards, and a contact footer.

## Project Overview

The page is designed to showcase upcoming workshops for CCT students and provide a clean, modern layout for browsing session information.

## Files Included

- `index.html` – main page structure
- `css/style.css` – custom styling
- `css/normalize.css` – browser reset styles
- `assets/images/placeholder.svg` – placeholder image used in workshop cards

## How to View the Project

1. Open the project folder in your browser or use a local preview extension.
2. Open `index.html` directly in a browser, or run a basic local web server.
3. For example:

   ```bash
   python3 -m http.server 8000
   ```

4. Then visit `http://localhost:8000` in your browser.
